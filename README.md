The Collatz Conjecture
======================

The [Collatz Conjecture](https://en.m.wikipedia.org/wiki/Collatz_conjecture) is an unsolved mathematical problem. This repository is a simple webpage that explains and demonstrates how it works.

If you want to see it in action simply clone the repository, then open public_html/index.html in your browser.

Alternatively, you can view it at [my website](https://nickrichter.com/collatz-conjecture) or at [GitHub.io](https://nickrichter.github.io/collatz-conjecture).

The technical underpinnings are actually quite simple. The webpage itself describes the process. To see how I translated that into a functional bit of JavaScript, check out _DEV/js/main.js.
